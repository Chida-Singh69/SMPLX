The Problem: A Silent Digital Divide

Over 70 million Deaf/HoH individuals worldwide rely on sign language as their primary communication medium. Yet digital media accessibility remains critically insufficient:

  • Captions fail — they convey English text, not ASL grammar, spatial semantics, or handshape transitions
  • Human interpreters don't scale — professional ASL interpretation costs make live coverage economically infeasible
  • Existing avatar tools are shallow — restricted dictionaries, no novel input handling, visually unrealistic output

→ We need a scalable, linguistically accurate, visually realistic system that translates arbitrary English into ASL animation in real time.

🧠

Key Innovation: VAE Latent Blending

Instead of retrieving a single clip, we encode top-K semantically matched pose sequences into a shared latent manifold and perform similarity-weighted interpolation:

zblend = Σ(wi · zi) / Σwi  →  VAE Decode → [T × 182] SMPL-X

Why it works: Convex combinations in VAE latent space produce outputs that lie within the learned distribution of natural ASL motion — guaranteeing anatomical plausibility without hallucination artifacts.

Novel Contributions

  • VAE-Mediated Latent Blending — first application to ASL motion synthesis; enables novel animations beyond pure retrieval while staying on the learned manifold
  • Three-Tier Adaptive Retrieval — confidence-stratified cascade (full-sentence → VAE blend → spaCy chunking) achieving 94% total coverage
  • Vertex-Mask Garment System — geometry-driven outfit rendering via analytical masks & normal-offset proxy meshes, computed once, reused every frame
  • End-to-End Deployable Stack — production-ready API + polished React frontend + browser extension architecture
